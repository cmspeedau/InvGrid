# InvGrid 0.2.0

## GUI (Ender IO Inventory Panel style)
- Compact 195x222 panel screen: dark slate background, thin light border, no title text
- Single search box across the top; typing re-filters the grid live
- 9x6 scrollable icon grid with count labels in the corner of each cell
- Count formatting: raw up to 10,000, then "12k", then "3M"
- Empty states: "Grid empty" when no cells have items, "No matching items" when filtered
- Left-click extracts one stack's worth, shift-click extracts all of that type
- Hover tooltips unchanged (vanilla item tooltip)
