### Power (cheap on purpose)

- **Bio Burner** — the grid's entry-level generator. Costs ~4 planks + 1 log to
  craft and burns *organic* items (saplings, seeds, kelp, crops) for a modest
  20 FE/t. It deliberately rejects logs and coal so it stays a bio niche and
  can't be trivially solved with furnace fuel. Powers Basic panel bulk ops and
  the Advanced panel's wireless features; Basic panels viewing/searching stay
  free, so the grid is usable with zero power too.
